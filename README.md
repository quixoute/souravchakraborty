# Sourav Chakraborty — Modern Portfolio

Static GitHub Pages portfolio. Edit `portfolio-data.js` to curate projects.

## Local preview
`python -m http.server 8000`

## Hero video
The homepage is configured to play `Fight-hero.mp4` (1920px-wide H.264, muted, fast-start MP4). The compressed asset is approximately 9.3 MB. It must be added at the repository root before the hero video can play; the GitHub text-file connector cannot upload this binary asset. Until it is uploaded, the hero video source will return 404.

## Contact
The enquiry form posts via AJAX to Formspree endpoint `https://formspree.io/f/xyewbqgo`. Test a submission after deployment and confirm the notification recipient/verification in Formspree.

## Category thumbnails
Wedding Films uses the existing wedding YouTube film; Commercial Films uses the existing Mumuso video. Photography cards use images from the existing photography collections.
